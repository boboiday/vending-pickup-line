# Vending Machine Pickup Line

One pickup line, spoken by a vending machine flirting with a passing human — for the make.fun bounty "One Line, One Minute: The Vending Machine Pickup Line Contest".

> "Hey. You've been staring at my buttons for a minute — press B4 and I'll fall for you. Literally. I fall for everyone."

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Writes one line (max 200 characters) to `/output/entry.txt`. Deterministic: the same line every run, no network, no randomness.
